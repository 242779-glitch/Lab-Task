# Brew & Bean ☕️

A modern, responsive and interactive coffee shop website built with HTML, CSS, Bootstrap 5 and JavaScript.

## Overview

Brew & Bean is a premium coffee shop website designed with a modern business-oriented UI.

The project focuses on:

- Modern responsive design
- Professional coffee-shop branding
- Interactive menu
- Product filtering
- Menu search
- Shopping cart
- Quantity management
- Checkout flow
- Table reservation
- Newsletter subscription
- LocalStorage cart persistence
- Mobile-friendly navigation

The project is built as a frontend application and can later be connected to a backend, database and payment system.

---

## Features

### Modern Landing Page

The homepage includes:

- Premium hero section
- Coffee shop branding
- Call-to-action buttons
- Business statistics
- High-quality coffee imagery
- Responsive navigation

### Menu System

Customers can browse available products by category:

- All
- Coffee
- Cold Drinks
- Pastries

The menu also includes a live search feature.

### Shopping Cart

The website includes an interactive shopping cart with:

- Add to cart
- Remove item
- Increase quantity
- Decrease quantity
- Automatic subtotal calculation
- Automatic tax calculation
- Automatic total calculation
- Cart item count
- Persistent cart using browser LocalStorage

### Checkout

Customers can:

- Enter their name
- Enter phone number
- Select Pickup or Delivery
- Place an order through the frontend checkout flow

### Table Reservation

The reservation section allows customers to enter:

- Full name
- Phone number
- Date
- Time
- Number of guests
- Special requests

After submission, a reservation confirmation modal is displayed.

### Responsive Design

The website works across:

- Desktop
- Laptop
- Tablet
- Mobile

Bootstrap's responsive grid system is used together with custom CSS.
